
# Responsive Internship Board

A beginner-friendly internship listing website built using HTML, CSS and JavaScript.

## Features
- Display internship opportunities
- Search internships by title and company
- Filter internships by domain
- Responsive desktop, tablet and mobile layouts
- Empty search result message
- Keyboard accessibility

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
3. Search and filter internship opportunities.
